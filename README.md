# IA520 Integrated Process Project

This vendor-neutral project develops one organizational scenario through four
cumulative Classroom 50 milestones. It examines Systems, Applications and
Products at the process, data, control, interface, and decision-design level.
It does not require proprietary enterprise software or certification study.

## Project standard

Connect a customer outcome to internal roles, process states, data, decisions,
controls, interfaces, tests, and operating evidence. Preserve what changes
between milestones instead of silently replacing prior conclusions.

## Required paths

- `stakeholder_contract.md`
- `process_map.md`
- `requirements.md`
- `transaction_experience.md`
- `data_control_matrix.md`
- `decision_dashboard.md`
- `workflow_controls.md`
- `interface_contract.md`
- `test_evidence.md`
- `validation_report.md`
- `decision_record.md`
- `handoff_runbook.md`

Each Classroom 50 assignment points to the matching `MILESTONE_N.md`. Canvas is
the official submission, rubric, feedback, and grade record.

## Single-student participation

The work is individual. If no peer is enrolled, perform the customer, process
owner, analyst, control reviewer, and operator perspectives sequentially. Label
each role, preserve its challenge and response, and use instructor or simulated
stakeholder feedback wherever review is required.
